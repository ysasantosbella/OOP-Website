Java Object-Oriented Programming Concepts

Learn the fundamental principles of Object-Oriented Programming

1. Class

A class is a blueprint or template used to create objects. It defines the properties (variables) and behaviors (methods) of an object. 

                    class Car {

                    String brand;
                    int speed;

                    void drive(){
                    System.out.println("The car is moving");
                    }

                    }

2. Object

An object is an instance of a class. It represents a real-world entity and contains properties and behaviors defined in the class. 

                    Car myCar = new Car();

                    myCar.brand = "Toyota";
                    myCar.speed = 100;

                    myCar.drive();

3. Inheritance

Inheritance allows one class to inherit properties and methods from another class. This promotes code reusability. 

                    class Animal {

                    void eat(){
                    System.out.println("This animal eats food");
                    }

                    }

                    class Dog extends Animal {

                    void bark(){
                    System.out.println("The dog barks");
                    }

                    }

4. Encapsulation

Encapsulation is the process of hiding internal data and only allowing access through public methods. 

                    class Person {

                    private int age;

                    public void setAge(int a){
                    age = a;
                    }

                    public int getAge(){
                    return age;
                    }

                    }
