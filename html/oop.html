OOP Concepts

Learn the fundamental principles of Object-Oriented Programming

Concepts

1. Class 2. Object 3. Inheritance 4. Encapsulation

1.

Class

A class is like a blueprint or template. It defines what properties (variables) and behaviors (methods) objects of this type will have. 

class Car {

    String brand;
    int speed;

    void drive() {
        System.out.println("The car is moving");
    }

}

2.

Object

An object is an instance of a class. Think of it as a real-world entity created using the class blueprint. 

Car myCar = new Car();

myCar.brand = "Toyota";
myCar.speed = 100;

myCar.drive();

3.

Inheritance

Inheritance lets one class take on properties and methods of another class. This helps reuse code and avoid repetition. 

class Animal {

    void eat() {
        System.out.println("This animal eats food");
    }

}

class Dog extends Animal {

    void bark() {
        System.out.println("The dog barks");
    }

}

4.

Encapsulation

Encapsulation hides internal data and allows controlled access through public methods. This keeps the object safe and maintainable. 

class Person {

    private int age;

    public void setAge(int a) {
        age = a;
    }

    public int getAge() {
        return age;
    }

}
